# Top K Frequent Elements - Heap Approach (C++)

## Language Features Used
- **`std::priority_queue`**: With `std::greater` to create a min-heap.
- **`std::unordered_map`**: For frequency counting.
- **`std::pair`**: To store frequency-value pairs in the heap.

## Run Tests
```bash
g++ -std=c++17 solution.cpp -o solution && ./solution
```
