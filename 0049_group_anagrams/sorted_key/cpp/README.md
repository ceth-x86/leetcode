# Group Anagrams - Sorted Key Approach (C++)

## Language Features Used
- **`std::unordered_map`**: For $O(1)$ average case lookups.
- **`std::sort`**: To generate canonical keys.
- **`std::move`**: Efficiently transferring vectors to the result.

## Run Tests
```bash
g++ -std=c++17 solution.cpp -o solution && ./solution
```
